# Demo shot list

1–3 minutes. Screen recording of the local app (`npm run dev`, http://localhost:5173). Reviewers will not clone the repo. One browser window, no secrets, no other projects on screen.

If a line says “Draft restored”, click **Start fresh** before the first beat.

Cues are beats to say in your own words, not a script to read.

## Paste this idea

```
First Cut — a tiny web page for indie hackers and students about to start a two-hour build.

You paste a fuzzy idea and answer three short questions. You get one card: the kernel, who it is for, the core loop, and a Now / Later / Cut list. The cut list has reasons, so you feel the cost of scope creep before any code.

Eventually, a template library. Not tonight.
```

Who:

```
Indie hackers and students starting a two-hour build tonight
```

Working tonight:

```
I can paste an idea, answer three questions, and copy a markdown card
```

Tempted (one per line):

```
Accounts and auth
An LLM rewrite
A mobile app
Collaboration
```

## Beats

1. **Empty (about 10s).** Show the title and the empty idea box. Click **Continue**. Point at “Write the idea first.”
   Cue: this is the pause before an agent writes code.
2. **Idea (about 15s).** Paste the idea. Click **Continue**.
3. **Who (about 10s).** Paste the who-line. Click **Continue**.
4. **Tonight (about 10s).** Paste the finish line. Click **Continue**.
5. **Tempted (about 15s).** Paste the four lines. Click **See the cut**.
6. **Card (about 30s).** Hold. Read the kernel. Move across Now, then Later, then Cut. Stay on one **Why** line.
   Cue: the cut list, with reasons, is the point. The line under the columns says no model was called.
7. **Name and copy (about 20s).** Click the project name and leave it, or fix one word. Click **Copy as Markdown**. Switch to a plain text note and paste, so the markdown is visible on screen.
   Cue: this is what you’d drop in a README before building.
8. **Start over (about 10s).** Click **Start over**. Show the empty idea box.
9. **Optional draft (about 15s), only if you still have time.** Type a few words, reload, show “Draft restored”, click **Start fresh**.

Stop. Don’t open the editor unless the card is already on camera.
