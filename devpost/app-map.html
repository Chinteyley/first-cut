Reference map

First Cut

One page. You paste a fuzzy idea, answer three questions, and get a card with a Cut list. The card is built by rules in the browser. No account, no server, no model.

One action

See the cut. The diagram is the path from the button to the column on screen.

Reference route. This file does not mean anyone clicked through the files in an editor.

Three stops

1. src/App.tsx — continueFrom

Search for continueFrom. An empty idea stops here. “See the cut” only changes step to card.

2. src/lib/buildCut.ts — buildCut and reasonFor

Search for function buildCut. This is the whole transform: name, kernel, Now, Later, Cut. reasonFor is the guilt-trip line. No fetch.

3. src/components/CutCard.tsx — CutCard

Search for function CutCard. It draws the columns and calls copyText from src/lib/clipboard.ts. If that returns fallback, the markdown box opens.

To change this, start here

  • Wording on the card’s empty states and the honesty line: src/content.ts (emptyCopy, HONESTY).
  • Which sentence becomes the kernel, or what a temptation is accused of: src/lib/buildCut.ts.
  • Colors and the step motion: src/index.css (--color-accent, .step-enter).
  • After a rule change, run npm run check. The fixture lives in scripts/check-build-cut.ts.

A practice to reuse

scope.md cuts an LLM before any component exists. The demo’s kernel sentence is then locked in scripts/check-build-cut.ts against buildCut. On the next project, write the cut list first, keep the proof in one pure function, and add a check that fails if that proof drifts into a service you said you were not building.

Run it again

npm install then npm run dev, and open http://localhost:5173. npm run check and npm run build are the mechanical checks.

Draft and clipboard, if you need them

Where the sitting is stored

src/lib/storage.ts — loadDraft, saveDraft, clearDraft. Key first-cut-draft-v1 in localStorage. Not an account.

Where copy decides to give up

src/lib/clipboard.ts — shouldUseClipboardApi. Insecure pages and a rejected writeText both fall back to the selected box in CutCard.
